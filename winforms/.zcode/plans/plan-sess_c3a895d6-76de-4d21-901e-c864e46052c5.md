# Kế hoạch: Module Phiếu Thu / Phiếu Chi (style MISA AMIS)

## Tổng quan
Thêm module thu chi tiền mặt theo bố cục màn hình MISA AMIS (toolbar Thêm/Sửa/Xóa/In + bộ lọc ngày + tìm kiếm live + grid) và form nhập phiếu kiểu MISA (Đối tượng, Địa chỉ, Người nhận tiền, Lý do, Số tiền + **số tiền bằng chữ tự điền**). Giữ theme màu nâu/kem hiện tại của app cho đồng bộ (bố cục & thao tác theo MISA, không đổi màu app sang xanh MISA).

Quy ước bám sát codebase: bảng DB tên tiếng Anh số nhiều, service ADO.NET thường (không ORM), form list = UserControl code-by-hand, form nhập = modal Form, mọi thay đổi DB kèm script đánh số trong `db_scripts/`.

## 1. DB — bảng `CashVouchers` (1 bảng chung, cột Type phân biệt thu/chi)

```sql
CREATE TABLE CashVouchers (
    Id INT IDENTITY(1,1) PRIMARY KEY,
    Type NVARCHAR(10) NOT NULL,            -- 'thu' / 'chi'
    VoucherDate DATETIME NOT NULL,
    Code NVARCHAR(50) NOT NULL,            -- PT-0001 / PC-0001
    Partner NVARCHAR(255) NOT NULL,        -- Đối tượng
    PartnerAddress NVARCHAR(255) NULL,     -- Địa chỉ
    Receiver NVARCHAR(255) NULL,           -- Người nhận tiền (chi) / Người nộp tiền (thu)
    Reason NVARCHAR(500) NOT NULL,         -- Lý do nộp / rút tiền
    Amount DECIMAL(18,2) NOT NULL,
    PaymentMethod NVARCHAR(30) NULL,       -- Tiền mặt / Chuyển khoản / Thẻ
    AttachedDocs NVARCHAR(100) NULL,       -- Kèm theo (số chứng từ gốc)
    Note NVARCHAR(MAX) NULL,
    CreatedBy NVARCHAR(100) NULL, CreatedAt DATETIME NULL,
    UpdatedBy NVARCHAR(100) NULL, UpdatedAt DATETIME NULL
);
```

**Đánh số phiếu kiểu MISA**: `PT-0001` / `PC-0001` (đệm 4 số, tăng dần theo từng loại) — service sinh bằng `MAX(Code)` trong transaction lúc lưu, form tự điền sẵn nhưng cho sửa tay (giống MISA).

**2 nơi tạo bảng** (theo cơ chế hiện có):
- `Program.cs` khối migration khởi động (Program.cs:52-107): thêm `IF NOT EXISTS ... CREATE TABLE CashVouchers` — mọi máy client tự có bảng.
- `db_scripts/05_add_cash_vouchers_table.sql` (script số tiếp theo, theo README quy tắc idempotent + in kết quả kiểm chứng, comment ASCII không dấu): CREATE TABLE + INSERT idempotent dòng phân quyền mới cho các role + section `PRINT '=== KIEM CHUNG ==='`. Cập nhật bảng theo dõi trong `db_scripts/README.md`.

## 3. WinForms — 4 file mới + 3 file sửa

**`Forms/FrmCashVouchers.cs`** (UserControl danh sách, mô phỏng FrmInvoices bỏ lưới chi tiết):
- Ctor `FrmCashVouchers(string type)` — "thu"/"chi" khóa filter như FrmInvoices("in"/"out"); "" = mode Tất cả + combo lọc loại.
- Toolbar: tiêu đề, Từ ngày/Đến ngày (mặc định tháng hiện tại, format dd/MM/yyyy), ô tìm kiếm live (số phiếu/đối tượng/lý do), nút **➕ Thêm** (xanh lá) / **Sửa** (cam, bật khi chọn dòng) / **Xóa** (đỏ) / **🖨️ In** (xanh dương) — đúng palette app.
- Grid 1 bảng, cột kiểu MISA: Ngày phiếu, Số phiếu, Đối tượng, Địa chỉ, Người nhận/nộp, **Số tiền** (N0, căn phải), Hình thức, Ghi chú, Người tạo. Ẩn cột kỹ thuật.
- Footer tổng (Dock=Bottom, pattern FrmBatches): "Tổng thu: X | Tổng chi: Y | Chênh lệch: Z" theo dữ liệu đang xem.
- Double-click → FrmVoucherDetailView; Sửa → FrmVoucherEdit(v); reload + chọn lại dòng vừa thao tác (SelectById như FrmInvoices.cs:346).
- Phân quyền theo nút: ẩn Thêm/Xóa nếu không có quyền create/delete (pattern FrmProducts).

**`Forms/FrmVoucherEdit.cs`** (modal ~750x560, 2 ctor: `FrmVoucherEdit(string fixedType)` / `FrmVoucherEdit(CashVoucher)`):
- GroupBox "Thông tin phiếu": Loại phiếu (khóa khi cố định/sửa), Ngày phiếu, Số phiếu (tự sinh, sửa được), **Đối tượng** (combo gợi ý từ SupplierService + autocomplete; chọn NCC thì tự điền Địa chỉ; lưu tên lạ thì tự tạo NCC mới — mô phỏng FrmInvoiceEdit.cs:118-121, 420-428), Địa chỉ, Người nhận tiền/người nộp tiền (nhãn đổi theo loại), Lý do rút/nộp tiền, Hình thức thanh toán (combo Tiền mặt/Chuyển khoản/Thẻ), Kèm theo.
- GroupBox "Số tiền": NumericUpDown (ThousandsSeparator, như FrmProductEdit.cs:56) + ô read-only **Số tiền bằng chữ** tự cập nhật khi gõ.
- Ghi chú + nút Lưu (xanh)/Hủy; validation: số tiền > 0, lý do bắt buộc, cảnh báo số phiếu trùng; Enter di chuyển trường (ProcessCmdKey).

**`Forms/FrmVoucherDetailView.cs`** — modal xem Read-only toàn bộ trường + nút In (mô phỏng FrmInvoiceDetailView).

**`Helpers/VoucherPrintHelper.cs`** — clone InvoicePrintHelper (A4 dọc, chọn máy in + xem trước): tiêu đề "PHIẾU THU"/"PHIẾU CHI", khối thông tin (số phiếu, ngày, đối tượng, địa chỉ, người nhận/nộp, lý do, hình thức, kèm theo), dòng TỔNG CỘNG + **số tiền bằng chữ**, 3 ô ký: Người lập phiếu / Người nhận tiền (Người nộp tiền) / Thủ quỹ.
